# 开发路线图

## 阶段一：基础骨架

- 初始化前端、API 和 Worker
- 配置 PostgreSQL
- 完成用户登录
- 完成数据库迁移
- 建立统一日志和错误格式

## 阶段二：新闻处理链路

- RSS/API 采集
- 新闻标准化
- 基础去重
- 分类和地区识别
- AI 摘要
- 日报生成

## 阶段三：Web 产品

- 首页
- 新闻列表
- 新闻详情
- 历史日报
- 搜索和筛选
- 用户偏好

## 阶段四：管理后台与稳定性

- 新闻源管理
- 任务监控
- 摘要重新生成
- 日报编辑和撤回
- 失败重试
- 数据备份

## 阶段五：渠道与商业化

- 钉钉机器人
- 微信公众号
- 邮件推送
- 会员和订阅
- 专题报告
- 企业版和 API
